# 📒 记一笔 MoneyBook

> 一款**零网络、零账号、零广告**的本地记账应用 —— 你的每一笔账，只属于你的手机。

**记一笔（MoneyBook）** 是一款完全离线运行的 Android 记账应用，用 Kotlin + Jetpack Compose + Room 打造，遵循 MVVM 架构。从「记一笔」到「看统计、控预算、存目标、做备份」，覆盖个人记账的完整闭环。所有数据只保存在你自己的手机里——应用在系统层面就没有联网能力，也不含任何广告、埋点或统计 SDK。

---

## ✨ 为什么选择它

- 🔒 **绝对隐私**：**不申请 INTERNET 权限**（连网络状态权限都主动移除），不联网、不登录、不上传，数据只存在你的手机里
- 💰 **分毫不差**：金额以「分」为单位用 64 位整数存储，绝不产生浮点误差
- ⚡ **极简高效**：首页一键记一笔，支持「连续记账」，记完一笔不用来回跳转
- 📊 **看得懂的统计**：饼图、柱状对比、趋势折线、**日历热力图**，还有**同比环比**——花多花少一目了然
- 🎯 **不只是记账**：多账本、多账户、月度预算、分类预算、周期账单、存钱目标、记账提醒——一套完整的个人财务小管家
- 💾 **数据可带走**：JSON 备份、**AES-256-GCM 加密备份**、CSV 导出（Excel 直接打开），换手机不怕丢
- 🆓 **永久免费**：无广告、无内购、无登录，MIT 开源协议

## 🎯 功能总览

### 📝 记账核心

- **支出 / 收入**自由切换，金额键盘秒输
- **分类**：emoji 图标 + 名称，点选即记
- **备注**：随手记下这笔钱花在哪儿、和谁花的
- **日期**：默认今天，可**补记历史日期**；统计页日历上点任意一天可直接补账
- **账户**：记一笔时选择支付来源（现金 / 微信 / 支付宝 / 银行卡…）
- **账本**：记录自动归入当前账本，首页顶栏一键切换
- **附件**：每笔账单可附**截图 / 照片**或**任意文件**（详见「账单附件」）
- **连续记账**：记完一笔可选「继续记」——留在本页自动聚焦金额、自动清空上一笔附件，适合月底集中补录
- **增删改**：账单随时编辑 / 删除，列表长按直达

### 🗂 分类管理

- 内置默认分类：支出（餐饮 / 交通 / 购物 / 住宿 / 娱乐 / 医疗），收入（工资 / 红包 / 兼职）
- 支持**自定义增删改**，每个分类可配 emoji 图标
- 分类删除有账单时安全转移，不会丢失数据

### 👛 多账户

- 内置现金 / 微信 / 支付宝 / 银行卡等常用账户，可自由增删改
- 记一笔时选择账户，账单行显示账户标识
- **删除账户时账单自动转移**到默认账户，数据零丢失

### 📒 多账本

- 支持创建多个账本（旅行 / 家庭 / 工作 / 装修……），账账分明
- 账本管理页：创建、重命名、切换、删除
- 首页顶栏**一键切换账本**，统计数据、预算、目标全部跟随当前账本
- 周期账单可关联指定账本；CSV 导出支持**按账本导出**
- 首次安装自动创建「默认账本」，老数据无损归入

### 💰 月度预算

- 设置每月总预算，首页显示**预算进度条**
- 超支即时提醒，进度直观可见
- 预算跟随账本，多账本各自独立

### 🎯 分类独立预算

- 给每个支出分类**单独设月度限额**（如餐饮 1200、娱乐 300），不只做一个总预算
- 每个分类显示「当月已用 / 预算」进度条
- **≥ 80% 橙色预警**、**超支红色提醒**
- 首页预算区自动提示接近或超支的分类（最多 3 条）

### 🔁 周期账单（自动记账）

- 固定重复开销自动记：房租、通勤、会员订阅、工资……
- 支持**每周 / 每月 / 每年**周期，可设开始日期、启用 / 停用
- 应用启动时**自动补记**到期账单，不联网也能准时入账
- 周期账单关联账本，多账本互不干扰

### 🏦 存钱目标

- 设定目标金额 + 截止日期，**自动算出每月要存多少**
- 进度可视化，攒钱进度一眼可见
- 「存入」操作自动记一笔储蓄支出，账实同步
- 首页展示存钱目标卡片，随时查看进度

### ⏰ 记账提醒

- 每日定时提醒记账（本地通知，WorkManager 调度，重启后依然有效）
- 可自定义提醒时间，一键开关
- Android 13+ 自动请求通知权限，其它版本无需权限

### 📊 统计图表（4 种视图 + 4 个时间维度）

| 图表 | 说明 |
| --- | --- |
| 🥧 **分类占比饼图** | Canvas 原生自绘环形饼图，按分类看钱花在哪 |

- 时间维度：**日 / 周 / 月 / 年**自由切换
- 收支类型：**支出 / 收入 / 全部**三态切换（饼图、日历图支持）
- **同比环比**：本月对比上月、对比去年同期，消费涨跌自动算给你看

### 🔍 账单管理

- 账单列表按时间倒序、**按月分组**（组头显示当月收支合计）
- **关键词搜索**：备注内容快速定位
- **类型筛选**：只看支出 / 收入 / 全部
- **金额区间筛选**：按金额范围过滤流水

### 🖼 账单附件

- 记一笔时可添加**截图 / 相册图片**或**任意文件**（小票、合同、截图都行）
- 编辑页显示**图片缩略图 / 文件标识**，可一键移除
- 账单列表行显示附件小图标（🖼 图片 / 📎 文件）
- 编辑页支持**全屏大图**预览，文件可通过 FileProvider 调起系统应用打开
- 附件读取授权持久化，重启后缩略图依然可见

### 💾 数据备份与迁移

| 方式 | 说明 |
| --- | --- |
| **加密备份（.mbk）** | ZIP 容器（账单 + 附件）→ GZIP 压缩 → **AES-256-GCM 加密**，密钥由你的锁屏密码派生，**跨设备可恢复** |
| JSON 备份 | 明文格式，兼容所有历史版本导入 |
| CSV 导出 | Excel / WPS 直接打开，支持按账本导出 |

- 加密备份导出 / 导入均有密码弹窗引导
- 导入后**附件自动恢复**到私有目录，图片类型按备份元数据还原
- 加密备份恢复后**自动同步应用锁**设置，安全不打折
- 兼容旧版备份文件：v1 / v2 / v3 格式加密备份与历史 JSON 均可导入

### 🔒 应用锁

- **4~6 位数字密码**，加盐哈希存储，**绝不保存明文**
- **指纹 / 生物识别**解锁（系统级 BiometricPrompt，安全可靠）
- 回前台自动锁定，锁屏后自动唤起解锁页
- **安全联动**：设置密码自动启用应用锁；关闭应用锁自动清除指纹；未设密码不允许单独开指纹
- 忘记密码？数据随你——密码不可找回，但可通过「清除应用数据 + 导入加密备份」恢复

## ❓ 常见问题

**Q：会偷偷联网上传我的账单吗？**
A：不会。本应用**没有网络权限**，Android 系统层面就无法联网，也不包含任何广告或统计 SDK。

**Q：为什么会有「通知」「开机自启」权限？**
A：分别用于「每日记账提醒」和「周期账单自动补记」，全部在手机本地运行，不涉及任何联网。

**Q：换手机了怎么迁移数据？**
A：设置 → 导出加密备份（.mbk 文件，AES-256-GCM 加密压缩）→ 新手机导入即可。密码为你设置的应用锁密码，跨设备可恢复。

**Q：升级版本会丢数据吗？**
A：不会。数据库升级经过真实 SQLite 引擎自动化测试验证（累计 33 项断言），覆盖安装数据完整保留。

**Q：忘记应用锁密码怎么办？**
A：应用锁密码不明文存储（加盐哈希），无法找回；可清除应用数据重新使用（会清空账本，请先做好备份）。

**Q：记账提醒没收到通知？**
A：请确认系统已授予通知权限；部分品牌手机需在系统设置中允许「自启动 / 后台运行」。

**Q：v2.0.0 和 v1.7.x 有什么区别？**
A：功能完全一致。v2.0.0 是项目定稿后的**正式版**（文档与发布全面完善）；v1.7.1 作为更名「记一笔」后的纪念版本保留在 Releases 页。

## 🔨 技术栈与架构

| 分类 | 技术 |
| --- | --- |
| 语言 | Kotlin 1.9.24 |
| UI | Jetpack Compose（BOM 2024.06.00，Material 3），图表全部 Canvas 自绘 |
| 架构 | MVVM：Entity → DAO → Repository → ViewModel（StateFlow）→ Compose UI |
| 数据库 | Room 2.6.1（KSP），共 4 个版本、3 次迁移，全部经真实 SQLite 引擎自动化验证 |
| 偏好存储 | DataStore Preferences（主题、应用锁、引导状态） |
| 导航 | Navigation Compose |
| 生物识别 | BiometricPrompt（系统级，不支持指纹时自动降级密码） |
| 桌面小组件 | Glance AppWidget |
| 本地提醒 | WorkManager（每日提醒 + 开机补记周期账单） |
| 附件缩略图 | Coil（仅加载本地 Uri，不发起网络请求） |
| 加密备份 | GZIP + AES-256-GCM（javax.crypto） |
| 构建 | AGP 8.5.2 / Gradle 8.9，minSdk 28 / targetSdk 34 / compileSdk 34 |

**目录结构**：

```text
app/src/main/java/com/andersonlin/moneybook/
├── ui/          界面层：Compose 页面 + ViewModel
│   ├── home/            首页（汇总 / 预算 / 存钱目标 / 最近账单）
│   ├── bill/            记一笔 / 账单列表（搜索筛选 / 附件）
│   ├── stats/           统计（饼图 / 柱状 / 折线 / 日历热力图 / 同比环比 / 导出 PNG）
│   ├── category/        分类管理
│   ├── account/         账户管理
│   ├── ledger/          账本管理
│   ├── budget/          月度预算
│   ├── categorybudget/  分类独立预算
│   ├── recurring/       周期账单
│   ├── goal/            存钱目标
│   ├── lock/            应用锁（密码 / 指纹）
```
