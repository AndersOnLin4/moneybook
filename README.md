# 记一笔（MoneyBook）

> 一款完全离线运行的 Android 记账应用。不申请网络权限、不需要注册账号、不含广告，所有数据仅保存在设备本地。

[![Release](https://img.shields.io/badge/Release-v2.0.0-brightgreen)](https://github.com/AndersOnLin4/moneybook/releases/latest)
![Android](https://img.shields.io/badge/Android-9.0%2B-3DDC84)
![License](https://img.shields.io/badge/License-MIT-blue)

「记一笔」用于记录日常收入与支出，提供分类、账户、多账本、预算、周期账单、存钱目标、统计图表、备份导出等功能。应用基于 Kotlin + Jetpack Compose + Room 开发，采用 MVVM 架构，最低支持 Android 9.0，在小米 HyperOS 3.0.5.0 上测试通过。

## 产品特点

- **完全离线**：未申请 INTERNET 权限，也不含广告、统计或任何第三方数据收集组件
- **数据本地**：账单保存在设备上的 SQLite 数据库中，不经过任何服务器
- **金额精确**：金额以「分」为单位的整数存储，避免浮点误差
- **免费开源**：MIT 许可，无内购

## 功能说明

### 记账
- 记录支出或收入，可填写金额、分类、账户、备注与日期
- 日期可补记历史，也可在统计日历中选择日期直接补账
- 连续记账：保存一笔后可留在当前页面继续记录下一笔
- 每笔账单可附加图片或文件
- 支持编辑与删除

### 分类
- 内置常用收支分类，可自定义添加、修改、删除，支持 emoji 图标

### 账户
- 内置现金、微信、支付宝、银行卡等账户，可自定义
- 删除账户时，该账户下的账单自动转移到其他账户

### 账本
- 支持多个账本（如日常、旅行、工作），数据相互独立
- 首页顶栏切换账本，统计、预算、存钱目标跟随当前账本
- 周期账单与 CSV 导出支持按账本区分

### 月度预算
- 按月份设置总支出预算，首页显示进度，超支时提示

### 分类预算
- 为单个支出分类设置月度限额（如餐饮 1200、娱乐 300）
- 当月使用达到限额的 80% 时提示「接近预算」，超过限额时提示「已超支」

### 周期账单
- 固定周期的收支自动生成账单，支持每周、每月、每年
- 可启用或停用；打开应用时自动补记到期账单，月末与闰年边界自动处理

### 存钱目标
- 设置目标金额与截止日期，自动计算每月需要存入的金额
- 显示存钱进度；「存入」操作自动记录一笔储蓄支出

### 记账提醒
- 每日定时提醒记账（本地通知），时间可自定义

### 统计
- 四类图表：分类占比饼图、近 6 个月收支对比柱状图、近 12 个月趋势折线图、日历热力图
- 时间范围支持日、周、月、年；饼图与日历图支持支出、收入、全部三种类型
- 同比环比：显示本月与上月、去年同期的对比
- 日历图中点击日期可查看当天收支明细，并可直接补账
- 图表可导出为 PNG 图片（1080×1280）

### 账单查询
- 账单按月分组显示，组头显示当月收支合计
- 支持关键词搜索、收支类型筛选、金额区间筛选

### 附件
- 每笔账单可附加相册图片或任意文件
- 列表显示附件标识，编辑页可预览图片，文件可调用系统应用打开
- 附件随加密备份一起导出，导入时自动恢复

### 备份与导出
- 加密备份（.mbk）：账单与附件打包压缩后使用 AES-256-GCM 加密，密码为应用锁密码，可在其他设备上恢复
- JSON 备份：兼容历史版本的明文格式
- CSV 导出：可用 Excel 或 WPS 打开，支持按账本导出

### 应用锁
- 4~6 位数字密码（加盐哈希存储，不保存明文）与指纹解锁
- 应用回到前台时自动锁定
- 设置密码后自动启用应用锁；关闭应用锁时自动清除指纹设置

### 桌面小组件
- 显示当前账本的本月结余、收入、支出与预算剩余
- 提供快捷记一笔按钮与手动刷新

### 外观
- 支持深色、浅色、跟随系统三种主题

### 首次引导
- 首次启动时通过 6 页向导完成账本、分类、预算、应用锁的初始设置，可跳过

### 关于
- 显示应用说明与版本号（版本号与实际安装包一致）
- 提供作者联系方式与版权信息

## 安装

1. 打开 [Releases 页面](https://github.com/AndersOnLin4/moneybook/releases/latest)
2. 下载 `MoneyBook-v2.0.0.apk`
3. 将文件传输到手机后点击安装，系统提示「未知来源」时选择允许

系统要求：Android 9.0（API 28）及以上。旧版本可直接覆盖安装，数据自动保留。

## 常见问题

**应用会联网吗？**
不会。应用未申请网络权限，系统层面无法联网，也不包含广告或统计组件。

**为什么需要通知和开机自启权限？**
通知权限用于记账提醒，开机自启权限用于周期账单自动补记，两者均在设备本地运行。

**如何迁移到新手机？**
在设置中导出加密备份（.mbk 文件），在新设备上导入并输入原应用锁密码。备份与附件会一并恢复。

**升级版本会丢失数据吗？**
不会。数据库升级经过自动化测试验证，覆盖安装时数据完整保留。

**忘记应用锁密码怎么办？**
密码不明文存储，无法找回。可清除应用数据后重新使用，此前请先做好备份。

**收不到记账提醒？**
请检查通知权限是否开启；部分品牌手机需要在系统设置中允许应用自启动或后台运行。

**v2.0.0 与 v1.7.x 有什么区别？**
功能一致。v2.0.0 为正式版；v1.7.1 是应用更名「记一笔」后的纪念版本，保留在 Releases 页。

## 构建

<details>
<summary>技术栈与构建指南</summary>

- 技术栈：Kotlin 1.9.24 + Jetpack Compose（Material 3）+ Room 2.6.1 + MVVM，compileSdk 34 / minSdk 28
- 环境：Android Studio Koala（2024.1.1）及以上，JDK 17
- 命令行：`gradlew assembleDebug` 或 `gradlew assembleRelease`
- 发布签名：在 `local.properties` 中配置 `release.keystore`（密钥库不提交到 git）
- 数据库迁移测试：`tools/migtest/`，使用 sqlite-jdbc 在真实 SQLite 引擎上执行，累计 33 项断言

```text
app/src/main/java/com/andersonlin/moneybook/
├── ui/          界面层：Compose 页面与 ViewModel
├── data/        数据层：Entity / DAO / Repository / 备份加密 / 偏好
├── widget/      桌面小组件（Glance）
└── util/        工具类
docs/            软件工程文档
tools/migtest/   数据库迁移自动化测试
```
