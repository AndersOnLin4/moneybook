## ✨ 为什么选择它

- 🔒 **绝对隐私**：应用**不申请网络权限**，不联网、不登录、不上传，数据只存在你的手机里
- ⚡ **极简高效**：首页一键记一笔，支持「连续记账」，记完一笔不用来回跳转
- 📊 **看得懂的统计**：饼图、柱状对比、趋势折线，还有**日历热力图**——圆圈越大，那天花得越多

## 📲 下载安装

1. 打开 [**Releases 页面**](https://github.com/AndersOnLin4/moneybook/releases/latest)
2. 下载 `MoneyBook-*.apk`
3. 传到手机点击安装（提示「未知来源」时选择允许）

> 支持 **Android 9.0 及以上**的全部手机品牌，实测兼容小米 HyperOS 3.0。

## 🚀 立刻开始你的记账之旅

**第一次打开**：跟随引导页，1 分钟完成账本、预算与安全设置，也可以全部跳过直接开始。

**日常使用**：首页点 ➕ 记一笔（支持连续记账）→ 月底打开统计页看图表复盘 → 设置预算和存钱目标，让每一分钱都花得明白。

**数据安全**：定期「导出加密备份」，换手机、刷系统都不怕丢数据。

## ❓ 常见问题

**Q：会偷偷联网上传我的账单吗？**
A：不会。本应用**没有网络权限**，Android 系统层面就无法联网，也不包含任何广告或统计 SDK。

**Q：换手机了怎么迁移数据？**
A：设置 → 导出加密备份（.mbk 文件，AES-256 加密压缩）→ 新手机导入即可。密码为你设置的应用锁密码。

**Q：升级版本会丢数据吗？**
A：不会。数据库升级经过自动化测试验证，覆盖安装数据完整保留。

**Q：忘记应用锁密码怎么办？**
A：应用锁密码不明文存储（加盐哈希），无法找回；可清除应用数据重新使用（会清空账本，请先做好备份）。

**Q：记账提醒没收到通知？**
A：请确认系统已授予通知权限；部分品牌手机需在系统设置中允许「自启动/后台运行」。
