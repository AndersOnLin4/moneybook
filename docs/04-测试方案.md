# 记一笔（MoneyBook）测试方案与测试用例

> 文档版本：v1.1 ｜ 对应软件版本：记一笔 v2.0.0（正式版） ｜ 更新日期：2026-08-15

## 1. 测试方案

### 1.1 测试目标
验证「记一笔」功能完整性、数据可靠性、隐私约束（无网络）与多机型兼容性。

### 1.2 测试策略与层次

| 层次 | 手段 | 覆盖目标 |
| --- | --- | --- |
| L1 静态验证 | 编译期校验（Kotlin 类型系统 + Room KSP SQL 校验） | 全部 DAO 的 SQL 合法性、实体与数据库结构一致性、API 使用正确性 |
| L2 数据层自动化测试 | 真实 SQLite 引擎（sqlite-jdbc）执行迁移脚本并断言 | 数据库 v1→v2、v2→v3、v3→v4 三次迁移的列/默认值/外键/索引/数据完整性（8 + 17 + 8 = 33 项断言全部通过） |
| L3 产物验证 | aapt2 / apksigner 命令行核验 | APK 包名/版本/最低系统、签名有效性、权限清单（无 INTERNET）、应用名「记一笔」 |
| L4 真机功能测试 | 手工用例执行 + 界面截图记录 | 全部功能模块与边界场景 |
| L5 回归测试 | 每个版本发布前重跑 L2/L3 + 关键路径手工用例 | 防止功能回退 |

### 1.3 测试环境

| 项 | 配置 |
| --- | --- |
| 真机 | 小米 HyperOS 3.0.5.0（Android 15），真机安装 release 签名包 |
| 构建环境 | JDK 17 + Gradle 8.9 + AGP 8.5.2 + compileSdk 34 |
| 数据层测试 | JDK 17 + sqlite-jdbc 3.45.1.0（与设备一致的 SQLite 引擎行为） |

## 3. 测试结果

- **L2 数据层**：三次数据库迁移脚本自动化验证，断言 8 + 17 + 8 = 33 项，全部通过（真实 SQLite 引擎执行）。
- **L3 产物**：aapt2 验证包名/版本（versionCode 20 / versionName 2.0.0）/最低系统（API 28）/权限清单/应用名「记一笔」正确；apksigner 验证签名有效。
- **L4 真机**：按上表 29 项用例执行并逐项截图。
