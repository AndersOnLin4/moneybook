# 基于 Android Jetpack 的本地化个人记账应用的设计与实现

> MoneyBook 软件设计说明书 / 技术论文 ｜ 版本 v1.0

## 摘要

随着移动支付的普及，个人日常收支呈现小额、高频、多账户的特征，传统手工记账与云同步记账软件在隐私性与操作效率上均存在不足。本文设计并实现了一款**完全本地化**的 Android 记账应用 MoneyBook：系统基于 Kotlin 语言与 Jetpack Compose 声明式 UI，采用 MVVM 架构与 Room 数据库，实现了账单记录、分类与账户管理、多账本隔离、月度与分类双层预算、周期账单自动记账、存钱目标、统计图表中心（饼图/柱状/折线/日历热力图）、数据加密备份等核心功能。系统不申请网络权限，所有数据存储于设备本地，满足个人财务隐私要求。针对数据库多次版本演进而设计的迁移方案均通过真实 SQLite 引擎的自动化测试验证，保障了升级过程的数据无损。

**关键词**：Android；Jetpack Compose；MVVM；Room；本地记账；数据加密

## 1. 引言

### 1.1 背景与意义
个人财务管理是国民数字素养的重要组成部分。市面主流记账软件多采用账号体系与云同步，用户数据驻留第三方服务器，存在隐私泄露风险；同时部分软件功能臃肿、操作路径深，难以坚持记账。因此，设计一款零网络、零账号、操作轻量的本地记账应用具有现实意义。

### 1.2 主要工作
1) 完成需求分析，梳理 18 项功能性需求与 8 项非功能性需求；
2) 设计并实现 MVVM + Repository 三层架构与 8 表数据库模型；
3) 实现账本、分类、账户、预算、周期账单、存钱目标、附件、应用锁、提醒、小组件等完整功能；
4) 设计数据库版本迁移方案并用真实 SQLite 引擎自动化验证；
5) 实现基于 AES-256-GCM 与 GZIP 的加密备份机制。

## 2. 系统设计

### 2.1 总体架构
系统采用 Android 官方推荐分层架构：**UI（Compose）→ ViewModel → Repository → Room/DataStore**。UI 仅观察 StateFlow 状态；ViewModel 组合多个数据流并处理事件；Repository 封装事务与业务规则。该分层使界面、业务、数据三者解耦，具备良好的可测试性与可维护性（架构图详见《系统总体设计》）。

### 2.2 数据库设计
数据库包含账单、分类、账户、账本、月度预算、分类预算、周期账单、存钱目标 8 张表。核心设计决策：
- **金额以「分」为单位整数存储**，避免浮点误差；
- **日期以 epochDay 存储**，支持任意区间聚合查询；
- **外键 + 仓库层事务**保障引用完整性（删除账户自动转移账单等）；
- 数据库历经 v1→v4 四次演进，每次迁移均经自动化测试验证。

### 2.3 关键算法
- **周期账单生成**：以 `lastGeneratedEpochDay` 为游标，按周/月/年递推，月末（1月31日→2月28/29日）与闰年自动收敛，逐笔补记并在单事务内推进游标，天然防重复；
- **统计聚合**：利用 SQLite `strftime` 按日/月分桶聚合，柱状图与折线图共享同一窗口数据（年=12月、月=每日、周=7日、日=近7天）；
- **加密备份**：`JSON → GZIP → AES-256-GCM`，密钥由应用锁 PIN 经 SHA-256 派生，文件头标识实现导入格式自动识别。

## 3. 系统实现

### 3.1 关键技术选型
| 技术 | 选型 | 理由 |
| --- | --- | --- |
| 语言 | Kotlin | Android 官方首选，空安全、协程 |
| UI | Jetpack Compose + Material 3 | 声明式 UI，开发效率高，状态驱动 |
| 数据库 | Room 2.6（KSP） | 编译期 SQL 校验、Flow 响应式查询 |
| 偏好存储 | DataStore Preferences | 协程友好，替代 SharedPreferences |
| 后台任务 | WorkManager | 每日提醒定时任务 |
| 小组件 | Glance | Compose 风格声明式小组件 |
| 指纹 | AndroidX Biometric | 系统级生物识别 |
| 图片 | Coil | 本地 Uri 缩略图加载，无网络行为 |

### 3.2 功能实现要点
（1）**连续记账**：保存后保留类型/分类/账户/日期上下文，自动聚焦金额框，将重复操作降至最低；
（2）**多账本隔离**：活动账本 id 由 DataStore 持久化，所有查询以该 id 过滤，切换后各页面经 Flow 链自动刷新；
（3）**双层预算**：总预算与分类预算并存，采用「已用 ≥ 预算×80% 视为接近、≥ 预算视为超支」的预警策略，首页聚合展示；
（4）**日历热力图**：自绘月历网格，以日期数字外圈半径映射当日金额（sqrt 缩放），三态着色区分收支；
（5）**附件**：通过 SAF 文件选择器获取 Uri 并持久化读授权，图片经 Coil 仅加载本地内容。

## 4. 系统测试

- **数据层自动化测试**：三次数据库迁移脚本在真实 SQLite 引擎上执行，33 项断言全部通过（列定义、默认值、外键、索引、数据完整性、约束生效性）；
- **产物验证**：aapt2 与 apksigner 核验包名、版本、最低系统、权限清单与签名；
- **真机测试**：在小米 HyperOS 3.0.5.0（Android 15）上执行 22 项功能用例（详见《测试方案与测试用例》），覆盖功能、边界与异常路径。

## 5. 总结与展望

本文实现了一款隐私优先的本地化记账应用，完整覆盖个人记账场景，并通过工程化手段（编译期校验 + 迁移自动化测试 + 产物核验）保障质量。后续可在以下方向演进：日历视图补账、借贷往来管理、订阅扣费追踪、小票 OCR 识别等。
