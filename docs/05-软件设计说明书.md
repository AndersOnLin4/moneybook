# 基于 Android Jetpack 的本地化个人记账应用的设计与实现

> 记一笔（MoneyBook）软件设计说明书 / 技术论文 ｜ 文档版本 v1.1 ｜ 对应软件版本 v2.0.0（正式版）

## 摘要

随着移动支付的普及，个人日常收支呈现小额、高频、多账户的特征，传统手工记账与云同步记账软件在隐私性与操作效率上均存在不足。本文设计并实现了一款**完全本地化**的 Android 记账应用「记一笔」（MoneyBook）：系统基于 Kotlin 语言与 Jetpack Compose 声明式 UI，采用 MVVM 架构与 Room 数据库，实现了账单记录、分类与账户管理、多账本隔离、月度与分类双层预算、周期账单自动记账、存钱目标、统计图表中心（饼图/柱状/折线/日历热力图，支持日/周/月/年维度、同比环比与 PNG 导出）、账单附件、首次引导、应用锁、记账提醒、桌面小组件以及基于 AES-256-GCM 的加密备份（含附件打包，跨设备可恢复）等完整功能。系统不申请网络权限，所有数据存储于设备本地，满足个人财务隐私要求。项目历经 v1.0.0 至 v2.0.0 共 20 个版本演进，数据库多次版本迁移均通过真实 SQLite 引擎的自动化测试验证（累计 33 项断言），保障了升级过程的数据无损。

**关键词**：Android；Jetpack Compose；MVVM；Room；本地记账；数据加密

## 1. 引言

### 1.1 背景与意义
个人财务管理是国民数字素养的重要组成部分。市面主流记账软件多采用账号体系与云同步，用户数据驻留第三方服务器，存在隐私泄露风险；同时部分软件功能臃肿、操作路径深，难以坚持记账。因此，设计一款零网络、零账号、操作轻量的本地记账应用具有现实意义。

### 1.2 主要工作
1) 完成需求分析，梳理 20 项功能性需求与 8 项非功能性需求；
2) 设计并实现 MVVM + Repository 三层架构与 8 表数据库模型（v4）；
3) 实现账本、分类、账户、双层预算、周期账单、存钱目标、附件、应用锁、提醒、小组件、新手引导等完整功能；
4) 实现统计图表中心：四类图表、四时间维度、三态切换、同比环比与原生 Canvas PNG 导出；
5) 设计数据库版本迁移方案并用真实 SQLite 引擎自动化验证（33 项断言）；
6) 实现基于 AES-256-GCM、ZIP 容器与 GZIP 的加密备份机制，支持附件打包与跨设备恢复；
7) 历经 20 个版本迭代修复与完善，v2.0.0 定为正式版。

## 2. 系统设计

### 2.1 总体架构
系统采用 Android 官方推荐分层架构：**UI（Compose）→ ViewModel → Repository → Room/DataStore**。UI 仅观察 StateFlow 状态；ViewModel 组合多个数据流并处理事件；Repository 封装事务与业务规则。该分层使界面、业务、数据三者解耦，具备良好的可测试性与可维护性（架构图详见《系统总体设计》）。

### 2.2 数据库设计
数据库包含账单、分类、账户、账本、月度预算、分类预算、周期账单、存钱目标 8 张表。核心设计决策：
- **金额以「分」为单位整数存储**，避免浮点误差；
- **日期以 epochDay 存储**，支持任意区间聚合查询；
- **外键 + 仓库层事务**保障引用完整性（删除账户自动转移账单等）；
- 数据库历经 v1→v4 四次演进，每次迁移均经真实 SQLite 引擎自动化测试验证（8 + 17 + 8 = 33 项断言）。

### 2.3 关键算法
- **周期账单生成**：以 `lastGeneratedEpochDay` 为游标，按周/月/年递推，月末（1月31日→2月28/29日）与闰年自动收敛，逐笔补记并在单事务内推进游标，天然防重复；
- **统计聚合**：利用 SQLite `strftime` 按日/月分桶聚合，柱状图与折线图共享同一窗口数据（年=12月、月=每日、周=7日、日=近7天）；同比环比由相邻窗口数据差值计算；
- **日历热力图**：以日期数字外圈半径映射当日金额（sqrt 缩放），三态着色区分收支；
- **加密备份（v3）**：`JSON + 附件 → ZIP 容器 → GZIP → AES-256-GCM`，密钥由 `SHA-256(用户密码 + 固定盐)` 派生，文件头 magic 标识版本，导入自动识别 v1/v2/v3 与旧版明文 JSON；
- **图表导出**：Compose 1.6 无 GraphicsLayer 捕获 API，采用原生 `android.graphics.Canvas` 复刻图表渲染，输出 1080×1280 位图。

## 3. 系统实现

### 3.1 关键技术选型
| 技术 | 选型 | 理由 |
| --- | --- | --- |
| 语言 | Kotlin | Android 官方首选，空安全、协程 |
| UI | Jetpack Compose + Material 3 | 声明式 UI，开发效率高，状态驱动 |
| 数据库 | Room 2.6（KSP） | 编译期 SQL 校验、Flow 响应式查询 |
| 偏好存储 | DataStore Preferences | 协程友好，替代 SharedPreferences |
| 后台任务 | WorkManager | 每日提醒定时任务 |
| 小组件 | Glance | Compose 风格声明式小组件 |
| 指纹 | AndroidX Biometric | 系统级生物识别 |
| 图片 | Coil | 本地 Uri 缩略图加载，无网络行为 |
| 加密 | javax.crypto（AES-GCM） | 标准库实现，无第三方依赖 |

### 3.2 功能实现要点
（1）**连续记账**：保存后保留类型/分类/账户/日期上下文，自动聚焦金额框并清空附件，将重复操作降至最低；
（2）**多账本隔离**：活动账本 id 由 DataStore 持久化，所有查询以该 id 过滤，切换后各页面经 Flow 链自动刷新；
（3）**双层预算**：总预算与分类预算并存，采用「已用 ≥ 预算×80% 视为接近、≥ 预算视为超支」的预警策略，首页聚合展示；
（4）**日历热力图**：自绘月历网格，以日期数字外圈半径映射当日金额（sqrt 缩放），三态着色区分收支，点击弹窗展示当日明细并支持补账；
（5）**附件**：通过 SAF 文件选择器获取 Uri 并持久化读授权，图片经 Coil 仅加载本地内容；查看文件经 FileProvider 授权调起系统应用；
（6）**首次引导**：6 页向导批量创建账本/分类/预算（事务入库，创建即见），完成后写入 DataStore 标记，仅首次展示；
（7）**附件随备份**：附件文件与账单 JSON 同包加密（ZIP v2/v3），导入时按备份元数据还原文件类型并写回私有目录；
（8）**版本号自动同步**：设置页/关于页/作者卡统一读取 `BuildConfig.VERSION_NAME`，杜绝版本显示与安装包脱节。

## 4. 系统测试

- **数据层自动化测试**：三次数据库迁移脚本在真实 SQLite 引擎上执行，33 项断言全部通过（列定义、默认值、外键、索引、数据完整性、约束生效性）；
- **产物验证**：aapt2 与 apksigner 核验包名、版本、最低系统、应用名、权限清单与签名；
- **真机测试**：在小米 HyperOS 3.0.5.0（Android 15）上执行 29 项功能用例（详见《测试方案与测试用例》），覆盖功能、边界与异常路径，含跨设备备份恢复、版本显示一致性等新增场景。

## 5. 总结与展望

本文实现了一款隐私优先的本地化记账应用「记一笔」，完整覆盖个人记账场景（记账、预算、目标、统计、备份、安全、小组件、引导），并通过工程化手段（编译期校验 + 迁移自动化测试 + 产物核验 + 真机用例）保障质量，v2.0.0 定为正式版。后续可在以下方向演进：借贷往来管理（应收应付与还款提醒）、订阅扣费追踪（识别重复扣费并提醒）、小票/截图 OCR 识别（自动提取金额与商户）等。
