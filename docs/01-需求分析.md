# 记一笔（MoneyBook）需求分析说明书

> 文档版本：v1.1 ｜ 对应软件版本：记一笔 v2.0.0（正式版） ｜ 更新日期：2026-08-15

## 1. 项目概述

「记一笔」（MoneyBook）是一款完全本地化的个人记账 Android 应用。用户可记录日常收入与支出，并通过分类、账户、账本、预算、存钱目标、统计图表等多种维度管理个人财务。应用**不申请网络权限、不包含任何网络请求**，全部数据保存在设备本地，充分保护用户隐私。

- 开发语言：Kotlin
- UI 框架：Jetpack Compose（Material 3）
- 数据库：Room（SQLite，v4）
- 架构：MVVM（Model-View-ViewModel）
- 最低系统：Android 9.0（API 28），实测兼容小米 HyperOS 3.0.5.0
- 版本演进：v1.0.0 → v2.0.0 共 20 个版本，当前为 v2.0.0 正式版（v1.7.0 起由「记账本」更名「记一笔」）

## 2. 功能性需求

| 编号 | 模块 | 功能描述 |
| --- | --- | --- |
| FR-01 | 记一笔 | 记录账单：支出/收入切换、金额输入（最多两位小数，按「分」存储避免浮点误差）、分类选择、账户选择、备注、日期选择（支持补记历史日期与日历视图点日期补账）；新增、编辑、删除账单 |
| FR-02 | 连续记账 | 新增账单时提供「继续记」与「记完了」：前者保存后留在本页并自动聚焦金额框、自动清空上一笔附件，减少重复操作 |
| FR-03 | 分类管理 | 内置默认收支分类（餐饮/交通/购物/住宿/娱乐/医疗；工资/红包/兼职），支持自定义新增、删除（emoji 图标）；默认分类受保护 |
| FR-04 | 账户管理 | 内置账户（现金/微信/支付宝/银行卡），支持自定义增删；删除账户自动转移其账单 |
| FR-05 | 多账本 | 支持创建/切换/删除账本，每个账本拥有独立账单；首页顶栏一键切换；删除账本连带删除其账单并二次确认；CSV 与周期账单均支持按账本维度 |
| FR-06 | 首页 | 当月总收入/总支出/结余、今日收支、月度预算进度条与超支提醒、存钱目标卡片、最近账单预览、悬浮记账按钮 |
| FR-07 | 账单列表 | 时间倒序、按月分组（组头显示当月收支合计）、关键词搜索（备注/分类名）、类型筛选、金额区间筛选 |
| FR-08 | 统计 | 分类占比饼图（支出/收入/全部三态，日/周/月/年维度）、近 6 月收支柱状对比、近 12 月趋势折线、日历热力视图（圆圈大小表示当日金额，点击查看当日明细并可直接补账）、同比环比（对比上月/去年同期）、图表导出 PNG（原生 Canvas 渲染 1080×1280） |
| FR-09 | 月度预算 | 按「年-月」设置总支出预算，首页显示进度与剩余/超支 |
| FR-10 | 分类预算 | 每个支出分类按月设置独立限额，分类预算页显示已用/剩余/超支进度，首页提示接近（≥80%）或超支的分类 |
| FR-11 | 周期账单 | 每周/每月/每年自动记账（打开 App 自动补记），支持增删改与启用停用，处理月末与闰年边界，可关联账本 |
| FR-12 | 存钱目标 | 目标金额+截止日期，自动计算每月需存金额，进度条可视化；存入一笔自动生成「储蓄」支出账单并计入统计 |
| FR-13 | 账单附件 | 每笔账单可附加图片（系统相册）或任意文件（文件选择器）；列表缩略图/图标标识、编辑页全屏大图预览、FileProvider 调起系统应用打开文件；附件随加密备份打包，导入自动恢复 |
| FR-14 | 应用锁 | 4-6 位数字密码（加盐哈希存储）+ 指纹解锁；进入锁屏自动唤起指纹；未设密码不可开启指纹；安全联动（设置密码自动启用锁、关闭锁自动清除指纹）；加密备份恢复后自动同步应用锁设置 |
| FR-15 | 记账提醒 | 每日定时本地通知提醒记账，时间可自定义；Android 13+ 运行时申请通知权限 |
| FR-16 | 数据导出 | CSV 账单导出（Excel 可直接打开，按账本选择）；JSON 全量备份导出/导入恢复；加密备份 .mbk（ZIP 容器含账单与附件 → GZIP 压缩 → AES-256-GCM 加密，密钥由密码派生，跨设备可恢复，兼容 v1/v2/v3 历史格式） |
| FR-17 | 桌面小组件 | 显示本月结余/收支/预算剩余（或超支），一键快捷记账，支持手动刷新与记账后自动刷新 |
| FR-18 | 主题设置 | 深色/浅色/跟随系统三种模式，持久化保存 |
| FR-19 | 新手引导 | 首次启动展示 6 页向导（欢迎/账本/分类/预算/安全/完成）；引导中创建的账本、分类、预算创建即生效（完成引导立即可见）；支持逐步跳过；仅首次展示 |
| FR-20 | 关于 | 应用简介与功能清单；版本号自动读取真实版本（BuildConfig.VERSION_NAME）；「关于作者」卡片（邮箱/微信一键复制、GitHub 仓库直达、著作权声明） |

## 3. 非功能性需求

| 编号 | 类别 | 要求 |
| --- | --- | --- |
| NFR-01 | 隐私安全 | 应用不申请网络权限（含网络状态权限），不产生任何网络请求；数据仅存储于本机 SQLite 数据库与私有目录 |
| NFR-02 | 数据安全 | 密码不明文存储（盐 + SHA-256 哈希）；加密备份采用 AES-256-GCM，密钥由用户密码派生、不落盘；数据库迁移无损升级，自动化验证 |
| NFR-03 | 兼容性 | 最低 Android 9.0（API 28），实测适配小米 HyperOS 3.0.5.0（Android 15）及其它主流品牌 |
| NFR-04 | 易用性 | 单手可操作；高频操作（记一笔、切换账本）路径最短；空数据状态友好引导；首次使用有 6 页向导 |
| NFR-05 | 性能 | 首页/统计数据通过 Room Flow 响应式刷新；金额使用整数（分）运算；图表 Canvas 自绘无第三方图表库 |
| NFR-06 | 可靠性 | 数据库迁移、备份导入等高风险操作用真实 SQLite 引擎自动化测试验证（累计 33 项断言）；关键操作二次确认 |
| NFR-07 | 可维护性 | MVVM 分层（Entity/DAO/Repository/ViewModel/UI），模块职责单一，代码注释完整 |
| NFR-08 | 无付费依赖 | 仅使用 Google 官方 Jetpack 与开源库（Coil 等），不包含任何付费 SDK 与广告；项目采用 MIT 协议开源 |
