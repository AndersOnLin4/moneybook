# 记一笔（MoneyBook）系统总体设计

> 文档版本：v1.1 ｜ 对应软件版本：记一笔 v2.0.0（正式版） ｜ 更新日期：2026-08-15

## 1. 总体架构

系统采用 **MVVM + Repository 分层架构**，基于 Android 官方推荐的应用架构：

```mermaid
graph TD
    subgraph UI层
        A[Compose 界面<br/>Home / Bill / Stats / Settings / Onboarding 等 17 个页面]
    end
    subgraph 视图模型层
        B[ViewModel<br/>StateFlow 状态 + 事件流]
    end
    subgraph 数据层
        C[Repository 仓库层<br/>业务规则与事务边界]
        D[Room DAO<br/>SQLite 数据访问]
        E[(SQLite 数据库<br/>moneybook.db v4)]
        F[DataStore<br/>主题/锁/账本/提醒/引导状态]
    end
    subgraph 系统服务
        G[WorkManager 每日提醒]
        H[Glance 桌面小组件]
        I[BiometricPrompt 指纹]
        J[SAF 文件选择器 备份/附件]
        K[FileProvider 附件查看]
    end
    A -->|"观察 StateFlow"| B
    B -->|"调用"| C
    C --> D --> E
    C --> F
    B -.->|调度| G
    H -.->|读取| C
    A -.->|调用| I
    A -.->|读写 Uri| J
    A -.->|附件 Uri 授权| K
    G -->|"本地通知"| A
```

**分层职责**：
- **UI 层**：Jetpack Compose 声明式界面，只观察 ViewModel 状态并回传用户意图；
- **ViewModel 层**：持有 UI 状态（StateFlow），组合多个数据流（combine/flatMapLatest），处理业务事件；
- **Repository 层**：封装数据来源（Room、DataStore）、事务边界（withTransaction）、业务规则（如删除账户转移账单、周期账单生成、引导期批量创建）；
- **数据层**：Room 提供响应式 Flow 查询；DataStore 持久化轻量偏好（含首次引导完成标记）。

**关键设计**：
- 金额一律以「分」（Long）存储，杜绝浮点误差；
- 日期以 `epochDay`（自 1970-01-01 的天数）存储，按区间查询汇总；
- 账单 → 分类/账户/账本为外键约束（RESTRICT），删除分类/账户/账本时由仓库层事务显式转移或级联清理；
- 数据库 1→2→3→4 共三次版本迁移，每次迁移均通过真实 SQLite 引擎的自动化测试验证（8 + 17 + 8 = 33 项断言全通过）。

## 4. 关键业务流程

### 4.1 周期账单自动补记
App 启动 → `RecurringRepository.generateDue()` → 遍历启用中的周期账单 → 从 `lastGeneratedEpochDay` 按周期推算下一生成日（月末/闰年自动收敛）→ 逐笔插入账单并推进游标 → 全部在同一事务内完成，防重复、防部分写入。

### 4.2 加密备份（.mbk v3）
导出：全量数据 → JSON 序列化 → 与附件文件一起打包为 ZIP 容器 → GZIP 压缩 → AES-256-GCM 加密 → 写入 `.mbk` 文件。
密钥派生（v3）：`SHA-256(用户密码 + 固定盐 KEY_SALT_V3)`，不绑定设备，**跨设备可恢复**；历史 v1/v2 格式（基于密码哈希、设备绑定）仍可导入。
导入：读取文件头 magic（MBK3/MBK2/MBK1）识别格式 → 自动解密解压（旧版 `.json` 直接解析）→ 校验引用完整性 → 事务内整体覆盖恢复 → 附件写回私有目录（按备份元数据还原图片 MIME）→ 自动同步应用锁设置。

### 4.3 账本隔离
所有账单查询（首页汇总、列表、统计、小组件）均携带当前活动账本 id；活动账本由 DataStore 持久化，切换后各页面 Flow 自动重查。

### 4.4 首次引导
首次启动（DataStore `firstLaunchDone == false`）→ 展示 6 页向导（欢迎/账本/分类/预算/安全）→ 用户创建的内容经 Repository 事务即时入库 → 完成或跳过 → 写入完成标记 → 进入首页，创建即见列表；后续启动不再展示。

### 4.5 图表导出 PNG
统计页「导出」→ `ChartBitmapRenderer` 以原生 `android.graphics.Canvas` 将当前图表状态渲染为 1080×1280 位图（Compose 1.6 无 GraphicsLayer 捕获 API，故采用原生 Canvas 复刻渲染）→ 保存至相册/分享。
